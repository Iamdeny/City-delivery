## 🎯 Следующий шаг: "Категории и навигация"

### **Что будем делать (в стиле Самоката):**

1. **Хлебные крошки** для навигации по категориям (только на десктопе, как у Самоката)
2. **Горизонтальный скролл категорий** - уже есть, можно улучшить UX
3. **Быстрые фильтры** популярных категорий (чипсы категорий)
4. **URL-навигация** с сохранением состояния фильтров (SEO и шаринг)
5. **Улучшение навигации** между страницами товаров

**Примечание:** У Самоката НЕТ бокового меню категорий на мобильных - только горизонтальный скролл чипсов категорий.

## 🔧 Технический стек (актуален на 2026 год)

### Frontend (Next.js 15, React 19)
- **Framework**: Next.js 15 с App Router (React 19)
- **UI**: Tailwind CSS + Framer Motion
- **State Management**: Zustand
- **Data Fetching**: React Query (@tanstack/react-query)
- **Validation**: Zod
- **Type Safety**: TypeScript

### Backend (Node.js)
- **Framework**: Express.js
- **Database**: PostgreSQL
- **Cache**: Redis
- **Real-time**: Socket.io
- **Validation**: Zod
- **Security**: Helmet, CORS, Rate Limiting

### DevOps
- **Containerization**: Docker
- **Database**: PostgreSQL с PgBouncer
- **Scripts**: PowerShell (Windows) + Bash (Linux/Mac)

### Mobile (Android APK)
- **Expo SDK 56** + WebView → `frontend-next` ([`mobile/README.md`](mobile/README.md))
- Сборка тестового APK: `cd mobile && npx eas-cli build -p android --profile preview`
