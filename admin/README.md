# Админ-панель City Delivery

Интерфейс для просмотра аналитики (рекомендации «Советуем»: показы, клики, CTR).

## Как запускать

### Локально (без Docker)

1. Установите зависимости и запустите бэкенд на порту **5000** (или 5001 — тогда настройте прокси ниже).

2. В папке `admin`:
   ```bash
   npm install
   npm run dev
   ```
   Или с явным портом:
   ```bash
   npm run start
   ```

3. Админка откроется на **http://localhost:3001**.

4. Запросы к API идут через прокси Vite: всё, что начинается с `/api`, проксируется на бэкенд (в `vite.config.js` по умолчанию `http://localhost:5000`). Если бэкенд у вас на другом порту, в корне `admin` создайте `.env`:
   ```
   VITE_API_URL=http://localhost:5001
   ```
   и перезапустите `npm run dev`. Либо поправьте `server.proxy` в `vite.config.js`.

### В Docker

Из корня проекта (где лежит `docker-compose.yml`):

```bash
docker compose up --build admin
```

- Админка будет доступна на **http://localhost:3001** (порт хоста 3001 → порт 80 внутри контейнера).
- Бэкенд должен быть запущен в той же сети (например, `docker compose up -d postgres redis backend`, затем `docker compose up admin`). Запросы `/api` из браузера проксируются nginx’ом внутри контейнера админки на сервис `backend:5000`.

Полезные команды:

```bash
# Поднять только БД и бэкенд, потом админку
docker compose up -d postgres redis backend
docker compose up admin

# Пересобрать админку после изменений
docker compose build admin && docker compose up admin
```

## Порт

| Режим        | Адрес                  | Порт |
|-------------|------------------------|------|
| Локально    | http://localhost:3001  | **3001** |
| Docker      | http://localhost:3001  | **3001** (маппинг на 80 в контейнере) |

## Разделы

- **Главная** — заглушка с ссылками.
- **Аналитика рекомендаций** — сводка по блоку «Советуем»: показы, клики, CTR, графики по дням, топ товаров (требуется бэкенд с эндпоинтами `/api/admin/analytics/recommendations/*`).
