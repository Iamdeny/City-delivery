# UI Design References

Эта папка содержит референсы UI для миграции компонентов.

## Структура

```
design/
├── README.md              # Этот файл
├── cart/                  # Референсы для корзины
│   ├── cart-modal.png     # Скриншот модального окна корзины
│   ├── cart-items.png     # Скриншот списка товаров в корзине
│   └── cart-empty.png     # Скриншот пустого состояния корзины
├── products/              # Референсы для продуктов
├── forms/                 # Референсы для форм
└── general/               # Общие референсы (цвета, типографика, spacing)
```

## Как использовать

1. **Добавьте скриншоты** в соответствующие папки
2. **Назовите файлы** понятно (например: `cart-modal-desktop.png`, `cart-modal-mobile.png`)
3. **Опишите в комментариях** ключевые особенности дизайна, если нужно

## Формат файлов

- **Изображения**: PNG, JPG, WebP
- **Размер**: рекомендуется 1920x1080 для десктопа, 375x812 для мобильных
- **Названия**: используйте kebab-case (например: `cart-modal-desktop.png`)

## Примеры использования

При миграции компонента я буду:
1. Изучать референсы из соответствующей папки
2. Адаптировать дизайн под Tailwind CSS
3. Сохранять визуальную идентичность и UX паттерны
