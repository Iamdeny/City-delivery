# Изображения для проекта

## Структура папок

- `promotions/` - изображения для карточек акций
- `bargain-shelf/` - изображения для товаров в секции "Выгодная полка"

## Как добавить изображения

1. Откройте сайт Самоката (samokat.ru)
2. Найдите секции "Акции" и "Выгодная полка"
3. Сохраните изображения в соответствующие папки
4. Используйте имена файлов, указанные в компонентах
